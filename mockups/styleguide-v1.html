Grundsätze

Was alle Apps gemeinsam haben

  • Kühle, neutrale Flächen; Haarlinien statt Schatten und verschachtelter Kacheln. Schatten nur für Dialoge.
  • Systemschrift, Zahlen immer mit fester Breite (tabular-nums), Beträge und Werte rechtsbündig.
  • Kleine Großbuchstaben-Kicker über Titeln, Kennzahlen und Tabellenköpfen.
  • Farbe sparsam: der App-Akzent für Aktion und „jetzt“, Status-Farben nur für Status, eine Datenfarbe für Diagramme.
  • „Jetzt“ (heute, aktuelle Woche, aktueller Monat) immer mit Akzentbalken links und weichem Verlauf.
  • Dunkle Kopfleiste in beiden Modi; Hell/Dunkel folgt dem System.
  • Handy zuerst: nie seitlich scrollen (342 px, große Systemschrift), Touch-Ziele mindestens 44 px.

Einbinden

So nutzt eine App den Styleguide

Geplant: Paket @overide6/ui mit tokens.css und base.css, optional ein Tailwind-Preset.

/* app.css */
@import "@overide6/ui/tokens.css";
@import "@overide6/ui/base.css";

:root {
  --app-accent-light: 13 118 108;  /* Kassenbons: Petrol */
  --app-accent-dark: 82 200 182;
}
/* tailwind.config.js (nur Apps mit Tailwind) */
presets: [require("@overide6/ui/tailwind-preset")]
/* → bg-surface, border-line, text-muted, text-accent, bg-accent/10 … */
